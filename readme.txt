A lead-generation theme for power equipment and outdoor machinery dealers.

== Description ==

Power Equipment Leads is a conversion-focused theme for dealers of generators, mowers, chainsaws and other outdoor power equipment.

The homepage is assembled from eleven sections — hero, quick stats, brand ticker, equipment categories, services, specials, financing, testimonials, FAQ, lead form and map — each one editable from Appearance > Customize > Homepage Sections rather than the block editor. Brand colours, business contact details and the header call-to-action are editable in the same place. Submitted enquiries are captured and stored for review in the WordPress admin.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.

== Frequently Asked Questions ==

= Does this theme support any plugins? =

Power Equipment Leads includes support for Infinite Scroll in Jetpack.
